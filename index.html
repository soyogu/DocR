DocR v1.9.0

🎉 DocR v1.9.0 アップデートのお知らせ

  • Windows / Mac 完全対応（v1.9.0）：これまでWindows版先行だった機能（記述統計・相関・Elastic Net・BART・各種新機能）を含め、全13機能がMac（Apple Silicon / Intel）でも完全に同等に動作するようになりました！
  • リアルタイム R 計算コンソール搭載：分析実行中、裏側で走るRコードや brms 等のMCMCサンプリング進捗がリアルタイムでコンソール画面に表示されるようになりました（結果シートへの再現用Rコード出力にも対応）！

手早い診断、深い洞察。

DocRは、brms 等の強力なR分析をExcel上で手軽に実行できるツールです。

「だれでも今日中にベイズ分析ユーザーになれる。」

データ分析の「最初の一歩」をスムーズに

  • 高度な統計モデルも直感的に実行できます。
  • Rのヘビーユーザーも納得の柔軟性（数式・カスタム引数の直接編集に対応）。
  • いつものExcelファイルをその場ですぐに分析（外部サーバーへのデータ送信は一切なし）。

操作画面（Excelだけで完結します）

普段お使いのExcelのリボンに「DocR」のメニューが追加されます。データの範囲を選んでクリックするだけで、裏側でRが走り、統計結果と編集可能なグラフが新しいシートに出力されます。

▲ Excel上で範囲を選んで実行するだけの操作イメージ動画

搭載している分析機能一覧（全13種・Win / Mac 共通）

  • Describe (psych) - 記述統計・分布プロット表示（平均・SD・歪度・尖度等の一覧、ヒストグラム＋密度曲線）
  • Correlation (correlation) - 相関分析（Pearson / Spearman / Kendall 等、ベイズ相関［BF・95% HDI］、偏相関、多重比較補正）
  • Linear Regression (lm) - 単回帰・重回帰分析（多重共線性診断［VIF］、限界効果・残差プロット、emmeans 多重比較）
  • GLM (glm / MASS::polr) - 一般化線形モデル・順序ロジスティック回帰（正規・二項・ポアソンに加え、Cumulative［順序ロジスティック回帰：予測クラス・確率出力］、VIF診断、多重比較に対応）
  • ANOVA (afex) - 分散分析（被験者間・被験者内・混合計画、球面性検定・自由度調整、emmeans 多重比較［Holm法］）
  • Linear Mixed (lmerTest) - 線形混合モデル（固定効果・変量効果、REML / ML推定、VIF診断、emmeans 多重比較）
  • Elastic Net (glmnet) - 正則化回帰（Lasso / Ridge / Elastic Net、交差検証による最適 α の自動探索、多項分類対応）
  • Bayesian (brms) - ベイズ階層モデル（正規・ベルヌーイ・二項・ポアソン・外れ値に頑健な student［Student-t］・順序累積・Cox・Weibull対応、Bayes R²・LOO、emmeans・hypothesis、未知データ予測＋95%信用区間、カスタム引数）
  • BART (dbarts) - ベイジアン加法回帰木（非線形回帰・2値分類、変数重要度、1次元・2次元部分従属プロット［PDP］、未知データ予測）
  • Factor Analysis (psych: fa / principal) - 探索的因子分析 / 主成分分析（スクリープロット・因子構造図、因子別クロンバック α・I-T相関の自動算出、因子得点・主成分得点のシート出力）
  • SEM / CFA (lavaan) - 構造方程式モデリング / 確認的因子分析（適合度指標・標準化推定値、FIML欠損値対応、パス図描画）
  • LPA / LCA (tidyLPA / poLCA) - 潜在プロファイル分析（連続変数）/ 潜在クラス分析（カテゴリ変数）（BIC最適クラス自動選択・所属クラス出力）
  • Text Mining（日本語専用：RMeCab） - 日本語テキストマイニング（形態素解析による頻出語抽出、属性別TF-IDFスコア、対応分析、共起ネットワーク、ワードクラウド、ユーザー辞書対応）

インストール・アップデートガイド

✔ はじめに Docker Desktop をインストールし、その後で DocR をインストールする順序になります。

✔ すでにPC/MacにRやRStudioが入っていても環境には一切干渉せず、すべての計算はPC内部（オフライン）で安全に完結します。

💻 動作環境・必要な空き容量の目安

  • OS・Excel：Windows 10 / 11（64-bit）または macOS（Apple Silicon M1〜M4 / Intel）＋ デスクトップ版 Microsoft Excel
  • 必要な空き容量（ストレージ）：10 GB 以上の空き容量を推奨（ダウンロードZIP：約 1.1 GB［内部ファイル docr_image.tar 約 1.3 GB］／展開後の Docker 統計エンジン：約 4.3 GB。ZIP解凍・イメージ読み込み時の一時領域を含みます。なお、アップデート時は古い DocR イメージが自動削除されるため容量は累積しません）
  • メモリ（RAM）：最小 8 GB（16 GB 以上を推奨 — Docker Desktop の稼働および brms・BART における MCMC サンプリングを快適に行うため）

ステップ0：Docker Desktop のインストール

👉 Docker Desktop の公式ダウンロードページ

  • 青い [Download Docker Desktop] ボタンからインストーラをダウンロードします。
    • Macをお使いの方：画面左上のリンゴマーク（）＞「このMacについて」を確認し、お使いのMacに合わせて Apple Silicon（M1 / M2 / M3 / M4 等） または Intel Chip を選んでください。
  • インストール中のチェックボックスはデフォルトのままでOKです（途中でアカウント登録を勧められた場合は「Skip」で問題ありません）。
  • 【重要】初回起動と規約への同意：インストール完了後（Windowsで再起動を求められた場合は再起動後）、DocRを入れる前に必ず一度「Docker Desktop」アプリを開き、最初の利用規約画面で「Accept」をクリックして起動を完了させてください。

ステップ1：DocR v1.9.0 のダウンロードとインストール

📥 Windows版をダウンロードDocR_Win_1_9_0.zip (v1.9.0) 📥 Mac版をダウンロードDocR_Mac_1_9_0.zip (v1.9.0 / Apple Silicon & Intel 対応)
⚠️ 実行前に必ずZIPファイルを「すべて展開（解凍）」してください！
WindowsではダウンロードしたZIPファイルを右クリック ＞「すべて展開...」で展開してから実行してください（ZIPをダブルクリックしただけのプレビュー画面から直接 Install_DocR.bat を開くと、同封のエンジンファイルが読み込めずエラーになります）。また、Excelが開いている場合は閉じておいてください。
  • 展開したフォルダ内にある Install_DocR.bat（Macでは Install_DocR_Mac.command）を実行します（統計エンジンの読み込みに2〜3分ほどかかります）。
    Windowsで青い警告画面（「WindowsによってPCが保護されました」）が出た場合

    メッセージ内の「詳細情報」という文字をクリックし、右下に現れる「実行」ボタンを押してください。

    Macで「開発元を検証できないため開けません」と警告が出た場合

    そのままダブルクリックせず、Install_DocR_Mac.command を右クリック（または Controlキー を押しながらクリック）し、メニューから「開く」を選択して実行してください。

  • 「[SUCCESS] DocR.xlam has been successfully installed.」（更新時は updated）と表示されたらセットアップ完了です！

ステップ2：Excelでのアドイン有効化（初回のみ）

Windows の場合

  1. Excelを開き、「ファイル」＞「オプション」＞「アドイン」をクリックします。
  2. 画面下部の管理「Excel アドイン」の横にある「設定...」ボタンを押し、「DocR」にチェックを入れてOKを押します。

Mac の場合

特別な設定は不要です。Excelを開くと上部のリボンに「DocR」タブが自動的に表示されます。

🔄 旧バージョンからのアップデート方法（アンインストールについて）

  • アップデートする際は、開いているExcelのウィンドウをすべて完全に閉じた状態で、新しいバージョンの Install_DocR.bat（Macは Install_DocR_Mac.command）を実行するだけです。
  • 古いDockerコンテナや旧バージョンのイメージはインストーラが自動的に削除・クリーンアップするため、ディスク容量を圧迫しません。Excelのアドイン設定もそのまま引き継がれます。
  • 不要になった場合も、フォルダに同封されている Uninstall_DocR.bat（Macは Uninstall_DocR_Mac.command）を実行すれば、アドインとDockerイメージを綺麗に削除できます。

使い方・ドキュメント

「まずは手を動かして試したい方」と「論文執筆や高度なモデル指定のために仕様を詳しく知りたい方」向けに、2つの資料を用意しています。

① 実践チュートリアル（Excelブック）

各分析手法のサンプルデータ、操作手順、出力結果のサンプルが1つのExcelファイルにまとまっています（配布ZIPにも同梱）。インストールしたら、まずはこのExcelファイルを開いてボタンを押してみてください！

📊 DemoBook.xlsx をダウンロード

② 技術仕様書・応用リファレンス

裏側で動くRパッケージ・推定アルゴリズム・デフォルト設定（学術論文の Methods セクション執筆にそのまま使える技術情報）や、カスタム数式・上級者向け構文レシピを網羅しています。Excelリボンの「DocR」タブ（設定・システム内の「マニュアル」ボタン、About の隣）からもワンクリックで開けます。

📘 技術仕様書・応用リファレンスを開く

最初に押さえておきたい「4つの基本仕様・便利ワザ」

1. 1行目ヘッダー込みで範囲選択 → リボンをクリック

データの1行目は自動的に変数名（ヘッダー）として認識されます。日本語の列名やスペース・() などの記号が含まれていても、内部で自動変換して安全に処理されます。

2. リアルタイム計算ログ表示＆Rコード出力

リボンの「Rコードを出力」をONにすると、実行中のRコードや brms 等のMCMC進捗がブラウザのコンソール画面にリアルタイム表示され、結果シート末尾にも再現用Rコードが記録されます。

3. グラフはExcel / パワポで編集可能なベクター画像（SVG）

出力されるグラフは高解像度なSVG形式です。ExcelやPowerPoint上で右クリックして「図に変換（グループ解除）」すれば、フォント・色・軸ラベルを自在に編集してそのまま論文図表に仕上げられます！

4. 未知データの自動予測＆数式の直接編集

brms や BART では目的変数（Y）だけ空欄にした行を用意して予測値出力をONにすると、予測値＋95%区間を自動算出！また、Formula欄やカスタム引数欄の手書き編集で交互作用や上級モデルも自在に実行できます。

AIを活用した分析・勉強のTIPS

分析の仕方も結果の読み方も、生成AIに聞くと驚くほどスムーズに理解できます。結果シートに出力されたサマリーやRコードを貼り付けて、ぜひお試しください！

プロンプト例：分析手法の相談
参加者に3種類の異なる香り（無臭、フローラル、シトラス）を嗅がせ、魅力度を評価してもらいました。参加者は30名で、データは『参加者ID』『香り条件』『写真ID』『魅力度スコア』という変数名でExcelに入っています。 Rのlmerで解析したいのですが、固定効果と変量効果には何を指定すべきですか？
プロンプト例：出力結果の解釈
Rのbrmsでこんな結果が出ました。[結果をペースト] これはどういう意味ですか？サマリーの中にある『R-hat』って何ですか？
プロンプト例：作業を減らす

よくある質問（FAQ）

無料で使えますか？

はい、学術研究・教育・個人利用の目的において完全に無料でご利用いただけます（詳細は下部の利用規約をご覧ください）。

複雑なモデルも扱えますか？

はい。ダイアログ上のモデル式（Formula）欄や brm() カスタム引数欄、lavaan シンタックス欄を直接編集できるため、交互作用・非線形モデル・事前分布の指定など上級者のニーズにも柔軟に応えます。具体的な書き方は 技術仕様書・応用リファレンス をご覧ください。

Mac版はありますか？

はい！ v1.9.0よりMac版（Apple Silicon / Intel 両対応）もWindows版と完全に同じ全13機能・最新仕様に統一されました。インストールするとExcelのメニューに自動で「DocR」タブが表示されます。

なぜDocRは既存のR環境と競合しないのですか？

DocRは、お使いのPC/MacのOSに直接Rをインストールするのではなく、「Dockerコンテナ」という独立した隔離空間の中でR（Ver 4.3.2）と厳選パッケージ群を動かすからです。既存のR環境を壊す心配がなく、ライブラリの依存関係やバージョン不一致に悩まされることもありません。

起動時や計算中に開くウィンドウは何ですか？

初回起動時にはバックエンドのDockerエンジンを起動するためのウィンドウや待機画面が表示されることがあります。また、リボンの「Rコードを出力」をONにしている場合、分析実行時にブラウザで黒い画面の「DocR - Real-Time R Calculation Console」（リアルタイムR計算コンソール）が開き、計算中のRコードやMCMCの進捗状況を表示します。いずれも計算後に閉じていただいて問題ありません（リボンからOFFにすれば自動で閉じます）。
