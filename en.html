🎉 What's New in DocR v1.9.0

  • Full Windows & Mac Feature Parity (v1.9.0): Every capability previously exclusive to Windows—including Descriptive Statistics, Correlation, Elastic Net, BART, and all latest updates—now works identically on Mac (Apple Silicon & Intel)!

Quick Diagnosis, Deep Insights.

DocR is an Excel add-in that lets you run powerful R statistical models—such as brms—directly from Excel.

"Anyone can become a Bayesian analysis user today."

Smooth "First Steps" in Data Analysis

  • Run advanced statistical models intuitively without writing boilerplate code.
  • Flexibility that satisfies power users of R (direct editing of formulas & custom arguments).
  • Analyze your Excel spreadsheets on the spot (100% local execution—zero data is ever sent externally).

User Interface (Complete Everything within Excel)

A "DocR" tab is added right to your familiar Excel ribbon. Simply select a data range and click; R runs in the background and outputs formatted results and editable vector plots to a new worksheet.

▲ Workflow overview video: simply select a cell range in Excel and click Run

Analytical Features Included (All 13 Modules — Win & Mac)

  • Describe (psych) - Descriptive Statistics & Distribution Plots (mean, SD, skewness, kurtosis, histograms & density curves)
  • Correlation (correlation) - Correlation Analysis (Pearson / Spearman / Kendall / Biweight / Distance, Bayesian correlation [BF & 95% HDI], partial correlation, p-value adjustment)
  • Linear Regression (lm) - Simple & Multiple Linear Regression (multicollinearity diagnostics [VIF], marginal effects & diagnostic plots, emmeans post-hoc tests)
  • GLM (glm / MASS::polr) - Generalized Linear Models & Ordinal Logistic Regression (Gaussian, Binomial, Poisson, plus Cumulative [Ordinal Logistic with predicted classes & class probabilities], VIF diagnostics, and emmeans post-hoc tests)
  • ANOVA (afex) - Analysis of Variance (between-, within-, and mixed-design ANOVA, Mauchly's sphericity test & corrections, emmeans Holm post-hoc tests)
  • Linear Mixed (lmerTest) - Linear Mixed-Effects Models (fixed & random effects, REML / ML estimation, VIF diagnostics, emmeans post-hoc tests)
  • Elastic Net (glmnet) - Regularized Regression (Lasso / Ridge / Elastic Net with cross-validated automatic α search; supports Gaussian, Binomial, Multinomial, and Poisson)
  • Bayesian (brms) - Bayesian Hierarchical Models (Gaussian, Bernoulli, Binomial, Poisson, robust student [Student-t], Cumulative, Cox, and Weibull families; Bayes R² & LOO-IC, emmeans, hypothesis testing, out-of-sample prediction with 95% CIs, custom arguments)
  • BART (dbarts) - Bayesian Additive Regression Trees (non-linear regression & binary classification, variable importance, 1D & 2D Partial Dependence Plots [PDP], out-of-sample prediction)
  • Factor Analysis (psych: fa / principal) - Exploratory Factor Analysis / Principal Component Analysis (scree plot & path diagram, automatic Cronbach's α & item-total correlations per factor, factor / component score sheet output)
  • SEM / CFA (lavaan) - Structural Equation Modeling / Confirmatory Factor Analysis (fit indices & standardized estimates, FIML missing data handling, path diagrams)
  • LPA / LCA (tidyLPA / poLCA) - Latent Profile Analysis (continuous) & Latent Class Analysis (categorical) (automatic BIC-optimal class selection & class membership output)
  • Text Mining (Japanese text only: RMeCab) - Morphological word frequency, attribute-based TF-IDF, correspondence analysis, co-occurrence network, word cloud, and custom dictionary support (visible when UI language is set to Japanese)

Installation & Update Guide

✔ Please install Docker Desktop first, and then install the DocR add-in.

✔ Even if you already have R or RStudio installed, DocR runs in an isolated container and will never interfere with your existing environment. All calculations run 100% locally offline.

💻 System Requirements & Recommended Disk Space

  • OS & Excel: Windows 10 / 11 (64-bit) or macOS (Apple Silicon M1–M4 / Intel) + Desktop Microsoft Excel
  • Storage (Free Disk Space): 10 GB or more of free disk space recommended (Download ZIP: ~1.1 GB [docr_image.tar ~1.3 GB inside] / loaded Docker statistical engine: ~4.3 GB, including temporary space during ZIP extraction and image loading. Note: updating automatically deletes old DocR images so disk usage does not accumulate.)
  • Memory (RAM): 8 GB minimum (16 GB or more recommended, especially for running Docker Desktop alongside MCMC sampling in brms and BART)

Step 0: Install Docker Desktop

👉 Official Docker Desktop Download Page

  • Download the installer using the blue [Download Docker Desktop] button.
    • For Mac users: Check Apple menu () > "About This Mac" and choose the installer matching your Mac—Apple Silicon (M1 / M2 / M3 / M4) or Intel Chip.
  • You can leave the checkboxes at their defaults during installation. If prompted to register an account, clicking "Skip" is completely fine.
  • [Important] Open Docker Desktop once & click "Accept": After installing Docker Desktop (and restarting Windows if prompted), open the Docker Desktop app once and click "Accept" on the initial service agreement before running the DocR installer.

On Windows, right-click the downloaded ZIP file > "Extract All..." first. Do NOT double-click Install_DocR.bat directly inside an unextracted ZIP preview window, or the bundled engine file will not be found. Also make sure Excel is closed before running the installer.
  • Run Install_DocR.bat (on Mac, Install_DocR_Mac.command) inside the extracted folder (loading the statistical engine takes about 2–3 minutes).
    If you see a blue warning screen ("Windows protected your PC") on Windows

    If you see an "unidentified developer" warning on Mac

Step 2: Enable the Add-in in Excel (First-Time Setup)

Windows

  1. Open Excel and go to "File" > "Options" > "Add-ins".
  2. Next to Manage: "Excel Add-ins" at the bottom, click "Go...", check the box for "DocR", and click OK.

Mac

No manual configuration required! Simply open Excel and the "DocR" tab will appear automatically in the top ribbon.

🔄 Updating from an Older Version (& Uninstalling)

  • To update DocR, simply close all open Excel windows completely and run the new Install_DocR.bat (or Install_DocR_Mac.command on Mac).
  • The installer automatically removes old Docker containers and images to save disk space, while keeping your Excel add-in settings intact.
  • If you ever wish to uninstall DocR, run the bundled Uninstall_DocR.bat (or Uninstall_DocR_Mac.command) to cleanly remove both the add-in and the Docker image.

4 Essential Tips & Core Specifications

1. Select Range Including Header Row → Click the Ribbon

The first row of your selected range is automatically treated as variable names (headers). Non-ASCII characters, spaces, and parentheses like () are safely handled via automatic internal aliasing.

2. Real-Time Calculation Console & R Code Output

Toggle "Output R Code" on the ribbon to watch executed R commands and live MCMC progress (brms, BART, etc.) stream in real time in a browser console, and append reproducible R code to your result sheet.

3. Editable Vector Graphics (SVG) for Publication Figures

All plots are inserted as crisp vector SVGs. Right-click a plot in Excel or PowerPoint and choose "Convert to Shape" (Ungroup) to freely customize fonts, colors, and axis labels for journal-ready figures!

4. Out-of-Sample Prediction & Direct Formula Editing

In brms and BART, leave the response variable (Y) blank on new rows and enable prediction output to automatically compute predicted values + 95% intervals! You can also hand-edit Formula and Custom Argument boxes for interactions and advanced models.

Frequently Asked Questions (FAQ)

Is it free to use?

Yes, DocR is completely free for academic research, educational, and personal use (please see the Terms of Use below for details).

Can it handle complex models?

Yes! Advanced users can directly edit the Formula box, brm() Custom Arguments (e.g., custom priors or adapt_delta), and lavaan model syntax to run bespoke models. See the Technical Specification & Advanced Reference for syntax recipes.

Is there a Mac version?

Yes! Starting with v1.9.0, the Mac version (supporting both Apple Silicon and Intel Macs) has 100% feature parity with Windows across all 13 analytical modules, and automatically adds the "DocR" tab to your Excel ribbon upon installation.

Why doesn't DocR conflict with my existing R installation?

DocR runs R (v4.3.2) and all pre-tested statistical packages inside an isolated "Docker container" rather than installing anything onto your host OS. Your existing R environment remains untouched, and you never have to deal with package compilation or version conflicts.

What are the windows that appear on startup or during calculation?

On initial startup, a Docker backend window or status splash screen may briefly appear while the local container wakes up. Additionally, when "Output R Code" is toggled ON in the ribbon, a browser window titled "DocR - Real-Time R Calculation Console" opens during calculation to display live R output and MCMC progress. You can safely close these windows after launch (or toggle "Output R Code" off on the ribbon).
