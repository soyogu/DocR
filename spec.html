DocR v1.9.0 技術仕様書・応用リファレンス

本書は、Excel アドイン型 R 統計解析ゲートウェイ DocR (v1.9.0) の内部アーキテクチャ、各分析モジュールの統計学的計算仕様（学術論文の Methods セクション執筆に必要なパッケージ・推定法・自由度計算・補正法等）、バックエンドの自動前処理・安全装置（フェイルセーフ）、および上級者向けのカスタム数式・構文レシピを網羅した公式技術仕様書です。

TIP / 実践テクニック

基本的なGUI操作チュートリアルとリボンからのクイック起動 「どのセルを選んでどのボタンを押すか」といった初歩的な操作手順やサンプルデータを用いた実践例については、配布サイト（https://soyogu.github.io/DocR/）および配布 ZIP 同梱の実践ワークブック DemoBook.xlsx、ならびに紹介動画をご参照ください。また、本仕様書（spec.html）は Excel リボンの「DocR」タブ内（「設定・システム」グループの 「マニュアル」 ボタン、About の隣）からもワンクリックでブラウザ表示できます。本書では UI 操作の逐次解説を省き、計算根拠と応用技法に焦点を当てています。

第1部：システム共通仕様・アーキテクチャ#

1.1 ローカル完結型コンテナアーキテクチャとMac完全対応 (v1.9.0)#

DocR は Microsoft Excel（フロントエンド UI・入出力シート管理）と Docker コンテナ内の隔離された Linux 版 R 実行環境（バックエンド統計計算エンジン）をローカル HTTP 通信で接続する 3 層アーキテクチャを採用しています。

text
[ Microsoft Excel (VBA Add-in: DocR.xlam) ]
        │  JSON over HTTP (http://127.0.0.1:8000) ※完全ローカル通信
        ▼
[ Docker Container: docr-api (Image: r-stat-api / Base: rocker/r-ver:4.3.2) ]
   ├── Port 8000: Python 3 マルチスレッドプロキシ & リアルタイムコンソール配信 (/app/server.py)
   └── Port 8001: R 4.3.2 + Plumber REST API サーバー (/app/api.R) + 事前コンパイル済み Stan モデル群
  • 完全ローカル実行とデータ秘匿性: すべての通信は PC 内部のループバックアドレス（127.0.0.1:8000）のみで完結します。選択した Excel データが外部のクラウドサーバーやインターネットへ送信されることは一切なく、機密性の高い臨床データ・人事データ・未発表実験データもオフライン環境で安全に解析できます。
  • 既存 R 環境との完全非干渉: 統計エンジンおよび全 R パッケージは Docker コンテナ（docr-api）内部に完全封入されています。ホスト OS 側に既に R や RStudio がインストールされていても、バージョン競合やパッケージ依存関係の破損は一切発生しません。
  • コンテナ自動起動とメモリ管理: 分析実行時に Docker Desktop や docr-api コンテナが停止していた場合、VBA 側（EnsureDockerRunning）が自動的にバックグラウンド起動・ヘルスチェック（GET /ping）を行います。また各エンドポイントの計算終了時には不要オブジェクトの明示的破棄とガベージコレクション（gc()）が実行され、大規模データや反復実行時のメモリ肥大化を抑制します。

  • Windows / Mac 完全機能統合 (v1.9.0):

    • v1.9.0 より、従来 Windows 版先行であった記述統計（Describe）、相関分析（Correlation）、正則化回帰（Elastic Net）、ベイジアン加法回帰木（BART）および各種拡張機能を含む 全 13 分析モジュールが Windows と macOS（Apple Silicon M1/M2/M3/M4 および Intel）で完全に同一仕様で動作します。
    • Apple Silicon (ARM64) 対応: ARM64 環境における旧版 dbarts の NEON ベクトル命令型不一致バグを回避するため、最新 CRAN パッケージをネイティブビルドして搭載しています。
    • Mac 版の文字コード無劣化パイプライン: Mac 版 Excel VBA 特有の内部 UTF-16LE エンコーディングと HTTP 通信制限を解決するため、iconv（UTF-16LE ⇔ UTF-8 双方向変換）とバイナリ curl（タイムアウト 1,800 秒）を組み合わせた専用ブリッジ（MacCurlPost）を実装し、日本語変数名・水準名・SVG グラフラベルの文字化けを完全に排除しています。
    • Mac ユーザーフォーム上のクリップボード統合: Mac 版 VBA の UserForm で標準では無効化されるキーボードショートカットを独自イベントハンドラ（MacTextBoxHandler）で補完し、数式欄やシンタックス欄での Cmd + C（コピー）/ Cmd + V（ペースト）/ Cmd + X（カット） をネイティブ同様に利用できます。

推奨動作環境・ディスク空き容量・メモリ要件#

  • 対応 OS および Excel: Windows 10 / 11（64-bit）または macOS（Apple Silicon M1〜M4 / Intel）＋ デスクトップ版 Microsoft Excel

  • ストレージ（必要な空き容量）: 10 GB 以上の空き容量を推奨

    • 配布リリース ZIP：約 1.1 GB（内部のイメージアーカイブ docr_image.tar は約 1.3 GB）、ロード後の r-stat-api Docker イメージ：ディスク上で約 4.3 GB（ZIP 解凍および docker load 実行時の一時領域を含め 10 GB 以上の余裕を推奨）。
    • なお、バージョンアップデート実行時はインストーラが旧バージョンの DocR コンテナ・イメージを自動的に削除してから入れ替えるため、更新を重ねてもディスク使用量が累積することはありません。
  • メモリ（RAM）: 最小 8 GB（16 GB 以上を推奨 — Docker Desktop のバックグラウンド稼働に加え、brms や BART における並列 MCMC サンプリングを快適に実行するため）

1.2 リアルタイム R 計算コンソール・再現用 R コード出力・リボン「マニュアル」ボタン#

ブラックボックス化しがちな GUI 統計ツールの課題を解消するため、DocR v1.9.0 では計算過程のライブ可視化、実行コードの完全な再現性、および仕様リファレンスへの即時アクセスを提供しています。

  • リボン「マニュアル」ボタンによるワンクリック参照:

    • Excel リボンの「DocR」タブ ＞「設定・システム」グループ（About ボタンの隣）にある 「マニュアル」（英語 UI: Manual） ボタンをクリックすると、現在の UI 言語設定に応じて日本語版仕様書（spec.html）または英語版仕様書（spec_en.html）が既定のブラウザで直接開きます。

  • リアルタイム R 計算コンソール (http://127.0.0.1:8000/console):

    • Excel リボンの「DocR」タブ内にある 「Rコードを出力」（英語 UI: Output R Code） チェックボックスを ON にすると、既定の Web ブラウザでローカルコンソール画面（http://127.0.0.1:8000/console）が自動的に立ち上がります（設定状態はアドイン内に保存されます）。
    • コンテナ内の Python プロキシ（server.py）が R プロセスの標準出力・標準エラー出力をアンバッファモードで捕捉し、300 ミリ秒間隔のポーリングによってブラウザへリアルタイム配信します。
    • 実行開始時刻、投入された R コード、brms（Stan）の MCMC サンプリング進捗（チェインごとの反復パーセンテージ）、BART のツリーサンプリングおよび部分従属プロット（PDP）計算状況、LCA の初期値反復状況、警告・エラーメッセージがリアルタイムで確認できます。
    • チェックボックスを OFF に切り替えると、コンソール画面へクローズ信号（/console_close）が送られ自動的に閉じます。なお、チェックが OFF の状態でも、長時間計算中にブラウザから手動で http://127.0.0.1:8000/console を開けばいつでも進捗を覗き見ることができます。

  • 結果シートへの再現用 R コード自動出力:

    • 「Rコードを出力」が ON の場合、出力シートの最下部に [ 実行されたRコード ] セクションが自動追記されます。
    • 内部の安全な変数エイリアスと元の Excel 列名の対応表（Variable Alias Mapping）および元のモデル式コメント（# Original Formula:）が併記されるため、出力されたコードをそのまま単体の R / RStudio スクリプトへ移植して検証・発展させることが可能です。

1.3 データ入力規則・型変換・ステルス変数エイリアシング#

データ範囲の選択と非破壊出力の原則#

  1. 1行目ヘッダー規則: 選択したセル範囲の 1行目は必ず変数名（列名） として処理され、2行目以降が観測データ（1行＝1観測／1レコードの整然データ：Tidy Data）として読み込まれます。列全体（例：A:F）を選択した場合でも、自動的にデータが存在する UsedRange との交差範囲のみが切り出されます。

  2. 最小データサイズと事前検証:

    • 記述統計 (describe): 2行 × 1列以上
    • 因子分析/主成分分析 (fa/principal): 3行 × 2列以上（選択項目 2 変数以上）
    • その他すべての分析モジュール: 2行 × 2列以上
    • 選択範囲内に Excel の数式エラー値（#DIV/0!, #N/A, #VALUE! 等）や空白のヘッダーセルが存在する場合、通信前に正確な行・列番号を通知して安全に停止します。
  3. 元データの絶対保護: すべての分析結果は <手法名>_Res_<時分秒>（例：lm_Res_152030）という新規ワークシートに出力され、1行目（A1 セル）に参照元データ範囲（例：Data Source: 'Sheet1'!A1:E120）が自動記録されます。元のデータシートが上書き・変更されることは一切ありません。

文字列・数値の自動型変換ルール#

  • 文字列（テキスト）データの自動因子化: 回帰・モデリング系モジュール（lm, glm, lmer, glmnet, brms, bart）では、文字データ列（例："Male" / "Female", "統制群" / "介入群"）は R 側で自動的に factor 型（カテゴリ変数） へ変換され、ダミー変数（デフォルトは辞書順の先頭水準を参照水準とする処理対比 contr.treatment）として推定に組み込まれます。

  • 数値でコーディングされたカテゴリ変数の扱い: グループ分けが "1", "2", "3" のような 数値 で入力されている場合、モジュールによって挙動が異なります。

    • ANOVA (afex) および LCA (poLCA): 数値であっても自動的にカテゴリ（因子）として強制変換されます（回帰の傾きとして誤計算される事故を防止します）。
    • lm, glm, lmer, brms, glmnet, bart: 数値列はそのまま連続変数（量的変数）として扱われます。数値コードをカテゴリ要因として扱いたい場合は、モデル式（Formula）欄で factor(群変数) と記述するか、Excel 側で文字列（"G1", "G2" 等）にしてください。

2段階ステルス変数エイリアシング機構 (DOCRVAR & ZVAR)#

R の数式パーサーは本来、日本語（マルチバイト文字）、スペース、括弧 ()、スラッシュ /、ハイフン -、パーセント % 等を含む列名を直接扱うと構文エラーを引き起こします。DocR は以下の 2 段階エイリアシングにより、Excel の自由な列名を維持したまま R の厳密な構文解析を両立させています。

  1. 第1段階：VBA ⇔ API ステルス置換 (DOCRVAR0001, DOCRVAR0002, ...):

    • すべての分析モジュールにおいて、VBA がデータと数式を JSON 化する直前に、全列名を衝突のない内部 ID（DOCRVAR0001 等）へ文字数の長い順かつ区切り文字境界判定付きで自動置換します。
    • R からの返却後、テキストサマリー（全角・半角の表示幅差分を計算して等幅フォントの桁揃えを自動補正）、JSON テーブル、および SVG 画像内のラベル文字列に至るまで、すべて元の Excel 列名へ完全に復元されます。

  2. 第2段階：brms 事前コンパイルキャッシュ用正規化 (ZVAR1, ZVAR2, ...):

    • brms モジュールではさらに、モデル式に登場する変数を登場順に ZVAR1, ZVAR2, ... へ正規化します。これにより、データセットや列名が異なっていてもモデル構造と確率分布が一致すればコンテナ内蔵の 事前コンパイル済み Stan C++ バイナリ（全 16 モデル） にヒットし、通常 30〜60 秒を要する C++ コンパイル時間をゼロに短縮します。
WARNING / 注意事項

brms で bf() 関数を直接記述する場合の重要な例外 brms のモデル式（Formula）欄を bf(...) で書き始めた場合（非線形モデルやカスタムサブモデル等）、第2段階の ZVAR 正規化および事前コンパイルキャッシュ参照がバイパスされます。また mvbind() や複雑な bf() 構文では Stan 内部で変数名の連結・変換が行われるため、bf() や mvbind() を使用する高度なモデリングでは、Excel 側の対象列名を半角英数字（例：score, time, group, ID）にして実行することを強く推奨します。

1.4 欠損値 (NA) の処理仕様と未知データの自動予測 (Out-of-Sample Prediction)#

Excel 上の空白セルは欠損値（NA）として認識されます。各分析モジュールにおける欠損値の処理方式は以下の通りです。

分析モジュールデフォルトの欠損値処理UI での切替選択肢・特記事項
Describe変数ごとに除外 (na.rm = TRUE)各変数の有効サンプルサイズ n を個別に算出
Correlationペアワイズ削除 (Pairwise)カテゴリ変数の自動ダミー化時も元の空白は 0 ではなく NA として厳密に保持（※偏相関 ON 時は完全ケース）
Linear Regression (lm)リストワイズ削除 (Listwise)モデル式に含まれる変数のいずれかが空白の行を除外
GLM (glm / polr)リストワイズ削除 (Listwise)除外後も元の有効行インデックス（Row）を保持して予測値・クラス確率を出力
ANOVA (afex)被験者単位／リストワイズ削除反復測定要因に1箇所でも欠損がある被験者は afex の仕様上丸ごと除外（欠損がある反復測定データには lmer を推奨）
Linear Mixed (lmer)観測行単位で除外 (Row-wise)欠損している特定の測定行のみを除外し、同一被験者の残りの有効データ行はすべて推定に活用
Elastic Net (glmnet)リストワイズ削除 (Listwise)モデル式内の使用変数に欠損のない完全ケースで交差検証を実行
Bayesian (brms)説明変数 X 欠損行を除外 ＋ Y 空白行の自動予測「予測値・残差を出力する」ON 時、Y が空白で X が揃っている行を未知テストデータとして予測
BART (bart2)欠損値インジケータ法 (保持) ＋ Y 空白行の自動予測X の欠損は「欠損値インジケータ法（保持）」と「リストワイズ削除」を UI で選択可能
Factor Analysis (fa/pca)ペアワイズ削除 (Pairwise)欠損検出時に「ペアワイズ削除」と「リストワイズ削除」を UI で選択可能
SEM / CFA (lavaan)完全情報最尤法 (FIML)欠損検出時に「完全情報最尤法 (FIML)」と「リストワイズ削除」を UI で選択可能
LPA / LCAリストワイズ削除 (Listwise)選択した観測変数群に欠損のない行を対象に分類し、被験者ID と紐付けて出力
Text Miningテキスト空白行の自動除外対象テキスト列が空欄の行を除外

未知データに対する自動予測機能（Out-of-Sample Prediction：brms & BART）#

ベイズ推定 (brms) および ベイジアン加法回帰木 (bart2) には、学習（推定）と未知データの予測を 1 回の実行で完結させる仕組みが組み込まれています。

  1. Excel シートの末尾（または任意の行）に、目的変数 Y のセルだけを空欄にし、説明変数 X（および変量効果のグループ ID）を入力した行 を追加します。
  2. ダイアログで 「予測値・残差を出力する」（Output Predictions & Residuals） にチェックを入れて実行します。

  3. バックエンドが自動的にデータを分割します：

    • 学習データ (df_train): Y と X がともに揃っている行でモデルを推定。
    • 予測対象テストデータ (df_test): Y が空欄かつ X が揃っている行に対し、推定済みモデルの事後予測分布（brms では fitted(..., allow_new_levels = TRUE)、BART では test = df_test）を適用。
  4. 出力シートの [ 予測値と残差 ] テーブルに、元の行番号（Row）とともに事後予測平均（Fitted）および 95% 信用区間（CI_Lower, CI_Upper） が算出されます（テストデータ行の Residual は NA となります）。

1.5 グラフ出力仕様：ベクターSVG編集と限界効果プロット#

論文品質のベクター画像（SVG）出力と Office 上での分解編集#

DocR が出力するすべてのグラフ・パス図・ネットワーク図は、ビットマップ（PNG/JPEG）ではなく svglite パッケージによるスケーラブル・ベクター・グラフィックス（SVG） として生成され、フォントフォールバック（'Hiragino Sans', 'MS Gothic', sans-serif）を適用した上でシートに埋め込まれます。

TIP / 実践テクニック

Excel / PowerPoint 上でグラフを論文投稿用に自在に編集する手順

  1. 出力シート上のグラフをコピーし、PowerPoint スライド（または Excel シート上）に貼り付けます。
  2. グラフを右クリックし、「図に変換」（Convert to Shape） を選択します（確認ダイアログで「はい」を選択）。
  3. 必要に応じて再度右クリックし、「グループ化」＞「グループ解除」（Ungroup） を実行します。 これにより、軸ラベル・タイトル・回帰直線・エラーバー・信頼区間リボン・データ点の 1 つ 1 つが Office ネイティブの図形オブジェクト に分解されます。投稿規定に合わせたフォント変更（Arial / Times New Roman 等）、文字サイズ拡大、日本語から英語ラベルへの書き換え、色調変更（グレースケール化等）を画質劣化ゼロで行えます。

「生データの平均」ではなく「調整済み限界効果（Marginal Effects）」を描画#

重回帰分析や混合モデル、一般化線形モデルにおいて、単純な 2 変数の散布図や生データの群平均を描画すると、他の共変量や個体差の交絡を含んだ誤解を招く図になります。DocR では各モデルの統計構造に即した 調整済み限界効果・推定周辺平均プロット を自動生成します。

  • lm / glm / lmer: ggeffects::ggpredict() により、焦点変数以外の共変量を平均値（または基準カテゴリ）に統制した純粋な予測値と 95% 信頼区間を描画します。特に glm（ロジスティック回帰・ポアソン回帰・順序ロジスティック回帰）では、逆リンク関数により対数オッズではなく「確率（0〜100%）」や「予測カウント」の直感的なスケールへ自動変換 して描画します。
  • ANOVA (afex): ggeffects::ggemmeans()（内部で emmeans を呼び出し）により、サンプルサイズの不均等や他要因を調整した 推定周辺平均（Estimated Marginal Means）と 95% 信頼区間 を描画します。
  • Bayesian (brms): brms::conditional_effects() による事後周辺効果（95% 信用区間付き）に加え、MCMC 収束診断用の トレースプロット（Trace Plot）と事後分布密度プロット を一括出力します。
  • BART (bart2): 変数重要度（Relative Variable Importance）棒グラフ、全説明変数の 1次元部分従属プロット（1D PDP；±1.96 SD 区間付き）、および重要度上位 3 変数ペアの 2次元交互作用ヒートマップ（2D PDP） を自動生成します。

  • 回帰診断プロットと多重共線性診断 (VIF):

    • lm, glm（cumulative を除く）, lmer では、等分散性・非線形性を点検する Residuals vs Fitted（lm/glm は赤色の LOESS 平滑化曲線付き）と残差の正規性を点検する Normal Q-Q プロット を自動併記します。
    • さらに v1.9.0 より、lm, glm（cumulative を含む）, lmer において説明変数の項が 2 つ以上 含まれる場合、performance::check_collinearity() が自動実行され、サマリー直下に === Variance Inflation Factor (VIF) ===（VIF 値、標準誤差膨張率、Tolerance 等；多水準カテゴリ変数の場合は一般化 VIF）が出力されます。

1.6 多重比較・事後検定の共通仕様 (emmeans & Holm法)#

ANOVA (afex)（チェックボックス ON 時）、および lm, glm, lmer, brms（Post-hoc タブ入力時）では、emmeans（Estimated Marginal Means）パッケージ を用いたペアワイズ多重比較（pairs(em, adjust = "holm")）を実行します。

  • p 値補正法：Holm 法（ステップダウン Bonferroni 法）:

    • すべてのペアワイズ比較において adjust = "holm" を標準採用しています。古典的な Bonferroni 法と全く同じ前提条件の少なさ（正規性や等分散性の崩れ・反復測定に対しても頑健で、常に第1種の過誤率 FWER を有意水準以下に厳密制御）を維持しつつ、Bonferroni 法よりも常に検出力（Power）が高い ため、現代の行動科学・医学・心理学において広く推奨される補正法です。
    • ※ brms（ベイズモデル）の場合: 頻度論的な p 値ではなく、事後分布から算出されたペア間の差の 事後中央値（estimate）および 95% 最高事後密度区間（lower.HPD, upper.HPD） が出力されます。区間が 0 を跨いでいなければ実質的な差があると解釈できます。

  • Post-hoc タブの指定構文（1行につき1指定）:

    • 主効果の多重比較: Group （Group の全水準ペアを比較）
    • 単純主効果の検定（Simple Main Effects）: Group | Time （Time の各水準ごとに、Group 間のペアワイズ比較を実行。連続変数×カテゴリ変数の交互作用モデルでも利用可能）
    • 交互作用の全セル総当たり比較: Group : Time （Group × Time の全組み合わせセル間で総当たり比較を実行）
  • factor() 自動除去フェイルセーフ: モデル式（Formula）欄で factor(Group) と記述したユーザーが、誤って Post-hoc 欄にも factor(Group) や as.factor(Group) と入力してしまっても、API 側の正規表現フィルタ（strip_factor_wrapper）が自動的にラッパーを除去して ~ Group へ変換するため、構文エラーで停止しません。

2.1 記述統計・データ概観 — Describe (psych)#

バックエンド・統計仕様#

  • エンドポイント / 実行関数: POST /describe — psych::describe(df) および ggplot2

  • 算出指標（一覧表出力）:

    • vars（変数番号）、n（欠損を除く有効観測数）、mean（算術平均）、sd（不偏標準偏差）、median（中央値）、trimmed（上下各 10% の外れ値を除外した 10% トリム平均）、mad（中央絶対偏差；正規分布換算係数 1.4826 乗算済み）、min（最小値）、max（最大値）、range（範囲）、skew（歪度）、kurtosis（尖度；正規分布を 0 とする超過尖度）、se（標準誤差 SD / sqrt(n)）。
  • グラフ出力: 密度スケール（after_stat(density)）のヒストグラム（デフォルト bins = 30、塗り色 steelblue）に、赤色のカーネル密度推定曲線（geom_density()）を重ねて描画します。複数変数選択時は facet_wrap(~ Variable, scales = "free") により各変数固有の軸スケールで一覧表示します。

自動前処理・安全装置 (Under the Hood)#

  • カテゴリ（文字列）データの自動数値コード化描画: 通常、文字列列をヒストグラムに投入すると型エラーになりますが、DocR はプロット生成時のみ非数値列を一時的に as.numeric(as.factor(x))（1, 2, 3... の連番）へ変換して描画します。ダミー変数化の手間なくカテゴリ水準の度数バランスを視覚確認できます。
  • 複数変数選択時の軸固定オーバーライド防止: 階級数（Bins）および X 軸範囲（Min / Max）の手動指定が有効になるのは 変数を 1 つだけ選択して詳細確認する時のみ です。2 つ以上の変数を同時選択した場合は、スケールの異なる変数群が共通軸で潰れる事故を防ぐため、UI 側・API 側の双方で自動的に scales = "free"（30 分割自動最適化）へ強制切り替えされます。なお、単一変数での Min / Max 指定にはデータを切り捨てない coord_cartesian(xlim = ...) を使用しているため、ズーム表示してもカーネル密度曲線が端で歪みません。

応用・カスタム構文レシピ#

  • パラメトリック検定前の分布スクリーニング: mean と trimmed（10% トリム平均）が大きく乖離している場合や、|skew| > 2・|kurtosis| > 7 を示す変数は強い歪みや外れ値を含んでいます。後続の回帰分析で対数変換 log(y) を適用するか、brms の student 分布（ロバスト回帰） や Correlation の spearman / biweight を選択する客観的根拠として活用できます。
  • 単一変数の外れ値ズーム確認: 極端な外れ値が 1 件あるためにヒストグラム本体が 1 本の棒に潰れてしまう場合、その変数 1 つだけを選択し、「階級(Bin)と描画範囲を自動最適化する」のチェックを外して Max（または Min）に上限値のみを入力することで、下限側は自動のまま本体分布を拡大観察できます。

2.2 相関分析 — Correlation (correlation)#

バックエンド・統計仕様#

  • エンドポイント / 実行関数: POST /cor — correlation::correlation()（easystats エコシステム）＋ BayesFactor（ベイズ相関 ON 時）

  • 相関係数の種類 (Correlation Method):

    • pearson（デフォルト）：ピアソンの積率相関係数 r（線形関係・パラメトリック）
    • spearman：スピアマンの順位相関係数 ρ（単調関係・順序尺度・外れ値に頑健）
    • kendall：ケンドールの順位相関係数 τ（同順位が多いデータや小標本に頑健）
    • biweight：Tukey の biweight 相関（M推定に基づく外れ値耐性の高いロバスト相関）
    • distance：距離相関（Distance Correlation；非線形・非単調な従属関係も検出可能で、値が 0 であることと統計的独立性が同値）
  • 多重比較 p 値補正 (p-value Adjustment): holm（デフォルト）、bonferroni、fdr（Benjamini–Hochberg 法による偽発見率制御）、none（無補正）。

  • 追加オプション:

    • ベイズ相関 (bayesian = TRUE): 各変数ペアに対してベイズファクター（BF10）および事後分布の 95% 最高密度区間（95% HDI）を算出します。
    • 偏相関 (partial = TRUE): 投入した他のすべての変数の影響を統計的に統制した偏相関係数を一括算出します。
  • 出力形式: 相関行列（正方マトリックス）ではなく、1行＝1変数ペアの エッジリスト形式（Parameter1, Parameter2, r / rho, 95% CI, t / S, df, p, n_Obs 等）で出力されます。

自動前処理・安全装置 (Under the Hood)#

  • 欠損値（NA）を破壊しない防弾ワンホット・ダミー化: 「カテゴリ変数を自動ダミー化して含める」（デフォルト ON）を有効にすると、文字列・因子列の各水準が <変数名>.<水準名>（例：性別.女性, 性別.男性）という 0/1 ダミー変数へ自動展開されます。一般的なダミー変換処理では元の空白セルが誤って 0 に置換されて相関係数が歪む罠がありますが、DocR では ifelse(df[[col]] == lvl, 1, 0) により 元のセルが欠損（NA）である行はダミー化後も厳密に NA のまま保持 し、ペアワイズ削除が正確に機能するよう設計されています。
  • エッジリスト出力の実務的利点: 数十変数の総当たり相関でも Excel のオートフィルタや並び替え機能で「p < 0.05 かつ |r| が大きい順」に即座に抽出でき、そのまま外部のネットワーク可視化ツールのエッジデータとしても利用できます。

応用・カスタム構文レシピ#

  • 「無相関の証拠」を論文で主張する（ベイズ相関の活用）: 頻度論の p > 0.05 は「相関がないことの証明」にはなりませんが、「ベイズ相関を計算する」を ON にして BF10 < 0.33（1/3 未満）が得られれば、「帰無仮説（無相関）が対立仮説の 3 倍以上支持された」という積極的根拠として論文に報告できます。
  • 重回帰投入前の多重共線性・交絡チェック: 説明変数候補を一括投入し、通常の相関（partial = FALSE）と偏相関（partial = TRUE）を比較することで、見かけ上の擬似相関と直接的な関連を切り分けることができます。

2.3 線形回帰分析 — Linear Regression (lm)#

バックエンド・統計仕様#

  • エンドポイント / 実行関数: POST /lm — stats::lm()
  • 推定法: 通常最小二乗法（OLS: Ordinary Least Squares）

  • 出力内容:

    • 回帰係数テーブル（推定値 Estimate、標準誤差 Std. Error、t value、両側有意確率 Pr(>|t|)）
    • モデル適合度指標（残差標準誤差 Residual standard error、決定係数 Multiple R-squared、自由度調整済み決定係数 Adjusted R-squared、モデル全体の F-statistic と p 値）
    • 多重共線性診断 (VIF): 説明変数の項が 2 つ以上ある場合、performance::check_collinearity(fit) による VIF テーブルを自動出力（一般に VIF < 5 が望ましく、VIF >= 10 は深刻な多重共線性を示唆）
    • 事後検定 (Post-hoc): 指定された項に対する emmeans + Holm 補正ペアワイズ比較
    • 予測値と残差テーブル: 有効行インデックス Row、当てはめ値 Fitted、残差 Residual
    • グラフ出力: 各説明変数の調整済み限界効果プロット（ggeffects::ggpredict）＋ 残差診断図 2 種（LOESS 曲線付き Residuals vs Fitted および Normal Q-Q）

自動前処理・安全装置 (Under the Hood)#

  • カテゴリ変数の自動因子化と共分散分析（ANCOVA）へのシームレス対応: 説明変数に文字列の群変数と連続値の共変量を同時に投入するだけで、自動的にダミー変数化が行われ、共分散分析（ANCOVA）や階層的重回帰と同等のモデルが構築されます。
  • 呼び出し式のクリーンアップ: fit$call$formula を整形して保持するため、サマリー出力の先頭に内部オブジェクト名ではなく明瞭なモデル式が印字されます。

自動前処理・安全装置 (Under the Hood)#

  • 逆リンク変換による「確率・回数スケール」での限界効果プロット: ロジスティック回帰や順序ロジスティック回帰の偏回帰係数は対数オッズ比（Log-Odds）であり直感的解釈が困難ですが、DocR は ggeffects::ggpredict() により 自動的に応答スケール（0%〜100% の発生確率や各順序カテゴリの選択確率推移）へ逆変換した曲線と信頼区間 を描画します。
  • cumulative モードにおける自動順序因子化と診断図制御: cumulative (Ordinal) 選択時、目的変数 Y は自動的に as.ordered() で順序付き因子へ変換されます（数値なら昇順、文字列なら辞書順）。また polr モデルでは単一スカラー残差が定義されないため、Residuals vs Fitted 等を自動抑制し、カテゴリ別の確率限界効果プロットのみをクリーンに描画します。
  • 欠損値を含むデータでの行ズレ防止: MASS::polr で欠損行がリストワイズ除外された際、rownames(fit$fitted.values) から有効行インデックスを厳密に取得して Row 列に記録するため、元データとの照合時に行ズレが発生しません。

  • オッズ比（OR）・発生率比（IRR）の算出: binomial や cumulative の偏回帰係数 β に対し、Excel 上で =EXP(係数) を計算すると オッズ比（Odds Ratio） が得られます。同様に poisson の係数に =EXP(係数) を適用すると 発生率比（Incidence Rate Ratio: IRR） になります。
  • ポアソン回帰でのオフセット項（観察期間や母数の補正）: 観察時間 time 当たりの発生率をモデル化する場合は、Formula 欄に以下のように offset(log(...)) を記述できます。

  • 順序ロジスティック回帰でのカテゴリ順序の制御: 文字列の目的変数（例："Low", "Mid", "High"）は辞書順（High < Low < Mid）になるため、Excel 側で "1_Low", "2_Mid", "3_High" または数値 1, 2, 3 としておくと意図通りの順序で閾値が推定されます。

2.5 分散分析 — ANOVA (afex)#

バックエンド・統計仕様#

  • エンドポイント / 実行関数: POST /anova — afex::aov_car()
  • 平方和のタイプ: Type III 平方和（Type III Sum of Squares） — 各要因の直交対比（contr.sum）が afex 内部で自動設定され、各群のサンプルサイズが不均等（アンバランスデザイン）なデータでも SPSS 等の商用統計ソフトと一致する不偏な主効果・交互作用検定を提供します。

  • 対応デザイン:

    • 被験者間計画（一元配置・多元配置分散分析：Between-Subjects Factors のみ指定）
    • 被験者内計画（反復測定分散分析：Within-Subjects Factors のみ指定）
    • 混合計画（スプリット・プロットデザイン：被験者間要因と被験者内要因の両方を指定）

  • 効果量と球面性補正の自動出力:

    • 効果量指標として 一般化イータ二乗（ges: Generalized Eta-Squared, η²G） を標準出力します（被験者間デザインと反復測定デザインの間で効果量の大きさを比較可能な推奨指標です）。
    • 3 水準以上の被験者内要因が含まれる場合、自動的に Mauchly の球面性検定（Mauchly's Tests for Sphericity）、および球面性の仮定が崩れた場合の Greenhouse-Geisser（GG eps, Pr(>F[GG])） と Huynh-Feldt（HF eps, Pr(>F[HF])） の自由度調整済み p 値を一括出力します（print(fit) のメイン ANOVA 表でもデフォルトで GG 補正後の自由度・p 値が表示されます）。

  • 事後検定とグラフ出力:

    • 「事後検定(Holm法)を行う」チェック時、主効果および交互作用項すべてに対して emmeans + Holm 補正ペアワイズ比較を自動実行します。
    • 主効果ごとに ggemmeans() による推定周辺平均と 95% 信頼区間プロットを描画します。

自動前処理・安全装置 (Under the Hood)#

  • 全要因の強制 factor 化による回帰誤認の防止: 群分けコードが 1, 2, 3 のような数値であっても、右辺に投入されたすべての要因・被験者 ID は API 側で自動的に as.factor() 変換されます。R 標準の aov() で頻発する「3群以上の数値コードを自由度 1 の直線回帰として誤計算してしまう事故」が構造的に防止されています。

  • 被験者間・被験者内に応じた Error() 項の自動構築: UI で割り当てた要因リストから、VBA が自動的に以下の aov_car 数式を組み立てます：

    • 被験者間要因のみ：Y ~ A * B + Error(Subject)
    • 被験者内要因を含む場合：Y ~ A * B + Error(Subject / (Within1 * Within2))

応用・カスタム構文レシピ#

  • 完全独立サンプル（対応のない分散分析）での 被験者ID 指定ルール:

    • afex::aov_car は観測の独立性／反復構造を厳密に識別するため、被験者間要因のみの分析であっても 被験者ID 列の指定が必須 です（1 人のデータが誤って複数行に分かれていた場合に平均化または警告するため）。
    • ID 列が手元のシートにない場合は、Excel で 1, 2, 3, ... の連番列を 1 列作成して 被験者ID に指定してください。
  • 欠損値がある反復測定データの対処: 反復測定デザインで一部の時点に欠損がある場合、ANOVA (afex) は欠損を持つ被験者をリストワイズ除外します。欠損行のみを除外して全データを活かしたい場合は、次節の 線形混合モデル (lmer)（例：Y ~ 条件 * 時点 + (1 | 被験者ID)）への切り替えを推奨します。

2.6 線形混合モデル — Linear Mixed (lmerTest)#

バックエンド・統計仕様#

  • エンドポイント / 実行関数: POST /lmer — lme4::lmer() ＋ lmerTest パッケージ拡張

  • 推定法:

    • デフォルト：制限付き最尤法（REML: Restricted Maximum Likelihood, REML = TRUE） — 分散成分（変量効果の分散・残差分散）の不偏推定に適した標準設定。
    • 「最尤法(ML)で推定する(モデル比較のため)」チェック時：完全最尤法（ML: Maximum Likelihood, REML = FALSE） — 固定効果の構成が異なるネストモデル間で AIC / BIC や尤度比検定によるモデル比較を行う際に使用。
  • 自由度と p 値の算出法: 標準の lme4 は p 値を出力しませんが、DocR は lmerTest をロードして推定するため、Satterthwaite の自由度近似法 による有効自由度（df）、t value、および有意確率 Pr(>|t|) が固定効果テーブルに自動出力されます。

  • 診断・事後検定・プロット:

    • 固定効果の項が 2 つ以上ある場合、performance::check_collinearity(fit) による VIF を自動出力。
    • Post-hoc タブ指定時、変量効果構造を考慮した emmeans + Holm 補正ペアワイズ比較を実行。
    • 個体差（変量効果）を統制した固定効果の限界効果プロット（ggeffects::ggpredict）＋ 残差診断図（Residuals vs Fitted, Normal Q-Q）を出力。

自動前処理・安全装置 (Under the Hood)#

  • 縦断・反復測定データの部分欠損に対する高い耐性: 欠損値が含まれる特定の観測行のみを除外し、同一参加者・同一クラスタの他時点データはすべて推定に利用します。また、参加者ごとだけでなく 刺激（アイテム）ごとのランダム効果も同時に組み込む交差型変量効果（Crossed Random Effects） にも対応しています。
  • 関数スコープ評価エラーを回避する環境バインディング: lmerTest と emmeans / ggeffects の組み合わせで生じやすい R 内部の環境参照エラーを防ぐため、評価時のみ一時的にスコープをクリーンに解決し on.exit() で即時消去する保護処理が実装されています。

応用・カスタム構文レシピ#

UI で「変量効果 (グループ化)」に 被験者ID や 刺激ID を追加するとランダム切片 (1 | ID) が自動生成されます。さらに Formula 欄を直接編集することで、ランダム傾きや階層（ネスト）構造を自在に記述できます。

2.7 正則化回帰 (Lasso / Ridge / Elastic Net) — Elastic Net (glmnet)#

バックエンド・統計仕様#

  • エンドポイント / 実行関数: POST /glmnet — glmnet::cv.glmnet()

  • ペナルティ構造とハイパーパラメータ:

    • L1 ペナルティ（Lasso：不要な変数の係数を厳密に 0 へ縮小して自動変数選択）と L2 ペナルティ（Ridge：強く相関する変数群の係数を安定的に縮小）を混合パラメータ α（0.0〜1.0）で統合します（α = 1: Lasso 回帰、α = 0: Ridge 回帰、0 < α < 1: Elastic Net）。
    • 正則化強度 λ は 10 分割交差検証（10-fold Cross-Validation） によって交差検証誤差（cvm）を最小化する lambda.min を自動選択します（※内部で説明変数の標準化 standardize = TRUE が自動適用され、出力係数は元の変数スケールに戻されます）。

  • 対応する分布族 (Distribution Family):

    • gaussian（連続量の線形回帰：二乗誤差最小化）
    • binomial（2値分類：二項逸脱度最小化）
    • multinomial（3クラス以上の多値分類：多項ロジスティック損失）
    • poisson（カウントデータ：ポアソン逸脱度最小化）

  • 出力内容:

    • 選択された α、最適 λ（lambda.min）、自動探索時は各 α（0.0〜1.0）の交差検証誤差一覧表（Alpha Search Results）
    • 非ゼロ係数一覧（Non-zero Coefficients）: lambda.min において係数が 0 にならず生き残った重要な変数のみを抽出表示（multinomial 時はターゲットクラスごとに表示）
    • 当てはめ値 Fitted（multinomial 時は各クラスの予測確率 Prob_<クラス名>）
    • グラフ出力（左右2分割）: 交差検証誤差曲線（CV Curve）と、赤破線で log(lambda.min) を示した係数パス図（Coefficient Path）

自動前処理・安全装置 (Under the Hood)#

  • α の 11 段階自動グリッドサーチ (Auto Search: 0.0-1.0): デフォルトの「自動探索」を選択すると、API 内部で α = 0.0, 0.1, 0.2, ..., 1.0 の 11 通りすべてに対して cv.glmnet() を実行し、最小交差検証誤差を達成した最適 (α, lambda.min) モデルを自動採用します。
  • model.matrix() による自動ダミー行列変換: glmnet は本来数値行列しか受け付けませんが、DocR は model.matrix(formula, df)[, -1, drop = FALSE] を介して文字列・カテゴリ変数や交互作用項を自動的にワンホット・デザイン行列へ展開してから投入します。
  • 多値分類 (multinomial) 時のプロット崩壊防止: multinomial 指定時は係数パス図を自動的に type.coef = "2norm"（全クラスにわたる係数ベクトルの L2 ノルム表示）へ切り替え、クラスごとのプロット重なりによる描画崩れを防ぎます。

応用・カスタム構文レシピ#

  • 純粋な Lasso 変数選択や Ridge 回帰の明示指定: 「値を指定 (Manual)」を選び、1 を入力すれば Lasso 回帰（スパースな変数選択）、0 を入力すれば全変数を残して多重共線性のみを抑える Ridge 回帰、0.5 を入力すればバランス型 Elastic Net として実行できます。
  • 全説明変数の総当たり 2 次交互作用からの自動特徴量選択: 変数数が中規模のとき、Formula 欄で (X1 + X2 + X3 + X4)^2 のように記述すると、すべての主効果＋2要因交互作用項を展開した上で、予測に効く交互作用だけを Lasso / Elastic Net に自動選抜させることができます。

自動前処理・安全装置 (Under the Hood)#

  • 16 種類の事前コンパイル済み Stan モデルとセッション内動的キャッシュ:

    • コンテナビルド時に頻出モデル 16 パターン（gaussian 単回帰・重回帰・交互作用・ランダム切片・ランダム傾き・2要因混合、student 単回帰・重回帰、bernoulli、poisson、cumulative 単回帰・重回帰・交互作用、lognormal 等）が C++ コンパイル済み .rds として /app/models に内蔵されています。一致するモデル構造では update() が呼ばれ、コンパイル待ち時間ゼロで直ちに MCMC サンプリングが開始されます。
    • 未登録の独自モデル式であっても、一度コンパイルされるとコンテナ稼働中はメモリキャッシュ（model_cache）に保持されるため、データを変えた 2 回目以降の実行は即座に開始されます（カスタム引数の MD5 ハッシュもキャッシュキーに反映されるため、事前分布変更時に古いモデルが誤用されることはありません）。

2.9 ベイジアン加法回帰木 — BART (dbarts::bart2)#

バックエンド・統計仕様#

  • エンドポイント / 実行関数: POST /bart — dbarts::bart2(..., keepTrees = TRUE)、pdbart()、pd2bart()
  • 統計アルゴリズム: 多数の浅い決定木（Sum-of-Trees）に正則化事前分布を課し、バックフィッティング MCMC によって非線形効果と高次交互作用をノンパラメトリックに自動学習するベイズ機械学習モデルです（過学習に極めて強く、事後予測分布から不確実性の信用区間も同時に得られます）。

  • 目的変数 Y の自動判別:

    • Y が数値列：連続値回帰 BART — 適合度として Pseudo R-squared（実測値と事後予測平均の相関係数の二乗）、RMSE、事後誤差標準偏差 Posterior Sigma を出力。
    • Y が 2 水準の文字／カテゴリ列：2 値分類プロビット BART — 内部で 0/1 に自動変換して分類モデルを構築し、正答率 Accuracy（閾値 0.5）および予測確率を出力（※3 水準以上のカテゴリ目的変数は対象外）。
  • デフォルト設定: 決定木数 n.trees = 100（UI 初期値）、Chains = 4、Iter = 2000、Warmup = 1000（各チェインのバーンイン n.burn = 1000、有効サンプル n.samples = Iter - Warmup = 1000）、Cores = 4。

  • 解釈可能な可視化出力:

    • Relative Variable Importance (%): 決定木の分岐ルールに各説明変数が採用された平均回数比率（合計 100%）のテーブルと棒グラフ。
    • 1D Partial Dependence Plots (pdbart): 他変数を周辺化した各変数の非線形主効果曲線（事後平均 ± 1.96 SD リボン／エラーバー付き）。
    • 2D Partial Dependence Plots (pd2bart): 重要度上位最大 3 変数の全ペアに対する 2 次元交互作用ヒートマップ。

自動前処理・安全装置 (Under the Hood)#

  • 欠損値インジケータ法（Missing Indicator Method：デフォルト）:

    • 実務データで説明変数 X に欠損がある場合でも行を捨てずに学習できるよう、以下の前処理を自動実行します：

      1. 数値型の説明変数: 欠損フラグ列 <変数名>_isNA（欠損なら 1、観測ありなら 0）を新規生成してモデル式に自動追加し、元の列の欠損セルには中央値（median）を代入します。
      2. 文字列／カテゴリ型の説明変数: 欠損セルを "Missing" という独立した 1 つのカテゴリ水準に変換します。
    • これによりサンプルサイズを 1 行も失わないだけでなく、「未回答・欠測であること自体が目的変数に対して持つ予測情報（非ランダム欠損：MNAR パターン）」も決定木の分岐条件として活用できます。
  • dbarts のテストデータ削除バグ回避ガード: dbarts::bart2 は本来、test データフレーム内の目的変数列が NA だと内部の model.frame 処理で行ごと削除してしまう仕様上の罠がありますが、DocR では分割後の df_test 側の目的変数列に一時ダミー値 0 を注入することで、Y 空白行に対する未知データ予測（事後平均と 95% 信用区間 2.5%〜97.5% 分位点）を確実に完遂させます。

応用・カスタム構文レシピ#

  • パラメトリックモデル（lm / brms）の探索的ベンチマークとして使う: どの変数に曲線効果（閾値効果・飽和効果）や交互作用が潜んでいるか事前仮説がない場合、まず BART に候補変数を一括投入し、1D PDP で非線形形状を、2D PDP ヒートマップで強い交互作用ペアを特定してから、lm や brms で理論モデルを定式化する 2 段階ワークフローが非常に有効です。
  • 決定木数 n.trees の調整指針: 主効果中心で解釈性を高めたい場合や小標本では n.trees を 50 前後に減らし、複雑な関数近似と予測精度を最大化したい大標本では 200 に増やすことで柔軟性を調整できます。

2.10 探索的因子分析・主成分分析 — Factor Analysis (EFA / PCA)#

バックエンド・統計仕様#

  • エンドポイント / 実行関数: POST /fa — psych::fa()（EFA モード）または psych::principal()（PCA モード）、ソート整形 psych::fa.sort()、信頼性分析 psych::alpha()

  • 選択パラメータ:

    • 分析モード: 探索的因子分析（EFA：共通因子モデル、デフォルト）／主成分分析（PCA：分散最大化による合成変数の縮約）

    • 因子抽出法 (Factoring Method、EFA のみ):

      • minres（デフォルト）：最小残差法（Minimum Residual / 普通最小二乗法 ULS と同等；正規性の仮定を要さず不適解が起きにくい推奨法）
      • ml：最尤法（Maximum Likelihood；多変量正規性を仮定し適合度指標を算出）
      • pa：主因子法（Principal Axis Factoring；反復共通性推定）

    • 回転法 (Rotation Method):

      • promax（デフォルト）：プロマックス斜交回転（因子間の相関を許容する心理・社会科学の標準法）
      • varimax：バリマックス直交回転（因子間無相関を仮定）
      • none：無回転
    • 欠損値処理: ペアワイズ削除（use = "pairwise"、デフォルト）／リストワイズ削除（use = "complete.obs"）

  • 出力内容:

    • psych 標準サマリー（固有値、説明分散比率、因子間相関行列、RMSEA / TLI / BIC 等の適合度 ※EFA 時）
    • 負荷量サイズ順に並び替え済みの 因子負荷量行列（または主成分負荷量行列）
    • 各下位尺度の Cronbach の α 係数テーブル および 項目別信頼性テーブル（I-T 相関 r.drop、項目削除時の α 係数 Alpha if dropped）
    • 因子得点 / 主成分得点テーブル ([ 因子得点 ] / [ 主成分得点 ])（※Output Factor Scores チェック時）：EFA は Thurstone の回帰法（scores = "regression"）、PCA は主成分重み付けにより算出し、元データの行インデックス Row 列付きで結果シートに出力します。
    • グラフ出力（上下2段）: 固有値減衰を示す スクリープロット（Scree Plot：因子分析固有値と主成分固有値の双方を描画） と 因子構造パス図（Factor Structure：psych::fa.diagram）。

自動前処理・安全装置 (Under the Hood)#

  • 下位尺度ごとの Cronbach's α 自動集計と逆転項目の自動反転 (check.keys = TRUE):

    • 抽出された各因子に対し、絶対値負荷量が最大となる項目群（2 項目以上）を自動的にグルーピングし、psych::alpha(..., check.keys = TRUE) を実行します。
    • 尺度内に逆転項目（負の負荷量を持つ項目）が未反転のまま混在していても、check.keys = TRUE により 自動的に負相関項目を検知・一時反転した上で正しい α 係数と I-T 相関を算出 します（手動反転忘れによる負の α 算出事故を防ぎます）。
  • 欠損値を含むデータでの因子得点の行整合性維持: 因子得点（主成分得点）は元データシートを破壊せず結果シートに出力され、Row 列に元のデータ行番号（1行目ヘッダーを除いたデータ行の連番 1, 2, ...）が明示されます。ペアワイズ削除時は全行分の Row が出力され（全項目欠損行は空欄）、リストワイズ削除時は有効行の Row 番号が正確に記録されるため、元シートへの結合時もズレが生じません。

応用・カスタム構文レシピ#

  • 最適因子数の決定プロセス: 初回実行時にスクリープロット（Scree Plot）で固有値が 1.0 を超える数（ガットマン・カイザー基準）および減衰の折れ曲がり点（エルボー基準）を確認し、さらに EFA サマリー内の RMSEA（< 0.08 目安）や TLI（> 0.90 目安）を比較して因子数を決定します。
  • 尺度精選と後続回帰への連携: [ 項目ごとの信頼性 ] テーブルで 削除時のα係数 が現在の因子 α より大幅に上昇する不良項目や、主因子負荷量が < .35 かつ他因子にも高く負荷する二重負荷項目を除外して再実行し、Output Factor Scores で得た因子得点をコピーして lm や brms の説明変数・目的変数に投入できます。

2.12 潜在プロファイル分析・潜在クラス分析 — LPA / LCA (tidyLPA / poLCA)#

バックエンド・統計仕様#

  • エンドポイント / 実行関数: POST /latent

    • 連続変数の潜在プロファイル分析 (LPA): tidyLPA::estimate_profiles()（オープンソース混合正規分布エンジン mclust による EM アルゴリズム推定）
    • カテゴリ変数の潜在クラス分析 (LCA): poLCA::poLCA()（多項分布潜在クラスモデル、EM＋Newton-Raphson ハイブリッド推定）

  • クラス数の自動探索と最適モデル選択:

    • 指定された最小クラス数 Min（デフォルト 2）から最大クラス数 Max（デフォルト 5）までの全モデルを一括推定し、全候補の適合度比較テーブル [ 適合度指標 (Fit Indices) ]（LPA は AIC, BIC, Entropy, prob_min, n_min 等；LCA は AIC, BIC, Gsq 尤度比統計量, Entropy）を出力します。
    • その中から ベイズ情報量規準（BIC）が最小となるクラス数 k* を最適モデルとして自動選択 し、その最適モデルに対するクラス別特徴量パラメータ、各被験者の [ 所属クラス一覧 ]（Subject, Class）、およびプロファイル／条件付き応答確率プロットを出力します。

  • LPA の分散・共分散構造モデル番号 (LPA Model):

    • 1（デフォルト推奨：EEI）: クラス間で分散が等しく、クラス内共分散を 0 に固定（最も安定して収束する標準プロファイルモデル）
    • 2（VVI）: クラスごとに分散が異なることを許容し、共分散は 0 に固定
    • 3（EEE）: クラス間で分散・共分散が等しいモデル
    • 6（VVV）: クラスごとに分散・共分散が自由に異なる非制約モデル（大標本向け）
    • (※注：tidyLPA の仕様上、モデル番号 4 および 5 は商用ソフトウェア Mplus 連携専用のため、DocR 内蔵のオープンソース mclust エンジンでは 1, 2, 3, 6 のいずれかを選択してください。)

自動前処理・安全装置 (Under the Hood)#

  • LCA における文字・0 始まりデータの自動正整数変換: poLCA は本来 1, 2, 3... の正の整数以外の値（0/1 ダミーや文字列 "Yes"/"No"）が入ると即座にエラー停止しますが、DocR は as.numeric(as.factor(x)) により任意の文字列や 0/1 データを自動的に 1 始まりのカテゴリ番号へ安全に変換します。
  • LCA の局所解回避とエントロピー独自算出: LCA は初期値依存性（局所最適解）を持つため、各クラス数につき nrep 回（デフォルト 10 回）のランダム初期値から反復推定して最大対数尤度解を採用します。さらに poLCA 標準では出力されない分類明確度指標 相対エントロピー（Relative Entropy） を事後所属確率行列 P（N 行 × K クラス）から次式（Entropy = 1 - sum(-P * log(P)) / (N * log(K))）で自動算出し、適合度表に付加します（1 に近いほどクラス分離が明瞭、> 0.80 が高分類精度の目安）。
  • LPA の自動 Z 得点標準化オプション: 「データを標準化する (Z-Score)」（デフォルト ON）により、単位やスケールの異なる連続変数群（例：年収と年齢と満足度スコア）を平均 0・SD 1 に揃えてからプロファイル抽出を行えます。

応用・カスタム構文レシピ#

  • 特定のクラス数（例：3クラス解）の結果を固定して取り出したい場合: BIC 最小解とは異なる理論的クラス数（例：3クラス）の所属リストやプロファイル図を出力したい場合は、最小クラス数 (Min) と 最大クラス数 (Max) の両方に同じ数値（Min = 3, Max = 3）を入力して実行してください。
  • 対象者セグメンテーション後の二次分析: 出力された [ 所属クラス一覧 ] の Class 列を元のデータシートへ結合すれば、抽出された潜在タイプを独立変数（ANOVA や GLM）や属性列（Text Mining）としてそのまま後続分析に展開できます。

2.13 日本語テキストマイニング — Text Mining (RMeCab)#

NOTE / 補足仕様

本モジュールは日本語形態素解析エンジン MeCab（mecab-ipadic-utf8 辞書） 専用に設計されているため、リボンの言語設定が 「日本語 (Japanese)」 のときのみメニューに表示されます。

バックエンド・統計仕様#

  • エンドポイント / 実行関数: POST /textmining — RMeCab::docDF(..., type = 1)（活用語を基本形・原型に正規化して文書×単語頻度行列を構築）
  • 抽出対象品詞 (POS Filter): デフォルトは 名詞・形容詞・形容動詞 の 3 品詞（オプションで 動詞・副詞・感動詞 を追加可能）。最低出現回数フィルタ（デフォルト min_freq = 5）以上の語を集計します。

  • 4 つの解析・可視化機能:

    1. 出現頻度テーブル ＆ TF-IDF 特徴語スコア（※属性 列指定かつ TF-IDF ON 時）：属性グループ数 N、語が出現した属性グループ数 df に対し、平滑化逆文書頻度 idf = log(N / df) + 1 を乗じた tf * idf を算出し、各単語が最も特徴づける属性（Top_Attribute）と TF-IDF_Score を降順出力します。
    2. ワードクラウド (wordcloud::wordcloud): 上位最大 100 語を出現頻度に応じた文字サイズと RColorBrewer Dark2 パレットで水平配置描画します。
    3. 共起ネットワーク (igraph): 文書×単語行列 X から共起回数行列 C = t(X) %*% X（対角成分 0）を算出し、正の共起回数の指定分位点（デフォルト閾値 0.90 ＝上位 10% の強い共起ペア）以上のエッジを無向重み付きグラフとして描画するとともに、[ 共起ネットワーク 繋がり強さ ] エッジリスト（単語1, 単語2, 共起回数）を数値出力します。
    4. 対応分析 (ca::ca)（※属性 列指定かつ 対応分析 ON 時）：単語×属性クロス集計表に対するコレスポンダンス分析を実行し、慣性（寄与率）サマリーと 2 次元バイプロットを描画します（※2次元プロットの描画には属性水準が 3 水準以上 あることが推奨されます）。

自動前処理・安全装置 (Under the Hood)#

  • オンデマンド MeCab ユーザー辞書の動的コンパイル: 複合語や専門用語・固有名詞（例：生成AI、カスタマーサクセス、推し活）が細かく分割されるのを防ぐため、「ユーザー辞書」欄に入力された語に対して生起コスト -30000（名詞,一般）を付与した CSV を生成し、コンテナ内の /usr/lib/mecab/mecab-dict-index をリアルタイム呼び出しして専用バイナリ辞書 user.dic を動的コンパイル・適用したのち即時クリーンアップします。
  • 1文字かなノイズの自動除去: 助詞の断片やフィラーに由来する 「ひらがな 1 文字」または「カタカナ 1 文字」の語（正規表現 ^[ぁ-んア-ン]$） は、除外語リストに手動登録しなくてもバックエンドで自動的に除外されます。

  • 「属性」指定有無による共起集計単位の切り替え仕様:

    • 属性 を空欄にした場合: Excel の 各行（1回答）を1文書 として扱うため、共起ネットワークは「同一回答内で一緒に使われた単語ペア」を表します（通常の自由記述全体の共起構造を見る場合はこちらを推奨）。
    • 属性 列を指定した場合: テキストが属性水準ごとに結合集約されるため、TF-IDF や対応分析による属性比較が有効化される一方、共起回数も属性グループ単位での集計となります。
